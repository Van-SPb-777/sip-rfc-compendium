# Двуязычный сборник RFC — веб-версия

- index.html — оглавление и поиск по содержимому всех книг;
- 
fc<N>.html — каждая книга: английский оригинал слева, русский перевод справа;
- pdf/ — те же книги в PDF (ландшафт A4).

Перевод выполнен с помощью ИИ, возможны неточности — сверяйтесь с оригиналом.
Исходные тексты RFC: https://www.rfc-editor.org/
